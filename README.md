# 🍽️ Sistema de Gerenciamento de Restaurantes

Este é um projeto simples de terminal em Python, desenvolvido com foco em reforçar conceitos de **Programação Orientada a Objetos (POO)**, **estruturas condicionais**, **listas** e **funções**.

---

## 🚀 Funcionalidades

- ✅ Cadastrar novos restaurantes
- ✅ Listar todos os restaurantes com status (ativado/desativado)
- ✅ Alternar o estado de um restaurante
- ✅ Interface limpa via terminal
- ✅ Menu principal com retorno automático após cada ação

---

## 🛠️ Tecnologias utilizadas

- [Python 3](https://www.python.org/)
- Bibliotecas padrão (`os`, `input`, `print`)
- Terminal interativo
